# BT-Batterytics

BT-Batterytics сообщает заряд устройств Bluetooth, запоминает время подключения каждого между двумя зарядками и показывает статистику.

Это изменённая версия [BlueToothBatteryReport](https://github.com/haitun001/BlueToothBatteryReport) от haitun001 и cary-rowen (см. «Благодарности и лицензия»).

Поддерживается несколько устройств: последовательно произносятся все устройства Bluetooth с определяемым зарядом. Порядок: подключённые, неизвестные, отключённые.

## Сочетание клавиш

- `NVDA+Shift+B` на компьютере без батареи (настольном), `NVDA+Alt+B` на компьютере с батареей (ноутбуке или планшете) — одно нажатие читает состояние батарей, двойное копирует отчёт в буфер обмена, тройное открывает настройки.

NVDA+Shift+B — собственная команда NVDA для состояния батареи. У настольного компьютера батареи нет, поэтому дополнение использует этот жест. На компьютере с батареей используется NVDA+Alt+B, сохраняя команду NVDA. Выбор делается при запуске NVDA по данным Windows; если определить нельзя, предполагается наличие батареи. Изменить жест можно в NVDA → Параметры → Жесты ввода, категория BT-Batterytics. Там же есть команда «Открыть статистику батарей Bluetooth», по умолчанию без жеста.

## Формат речи

При наличии сведений о заряде каждое устройство произносится так:

- `имя устройства, заряд xx%`

Можно добавить тип подключения и его длительность:

- `имя устройства (Classic), заряд xx%`
- `имя устройства (LE), заряд xx%`
- `имя устройства, заряд xx% (подключено 2 ч 5 мин)`

Если задано собственное имя (см. «Статистика батарей»), оно произносится вместо имени Windows.

## Настройки

Отдельная страница находится в NVDA → Параметры → Настройки → BT-Batterytics.

### Какие устройства сообщать

- **Сообщать о подключённых устройствах** — Произносить подключённые сейчас устройства (включено по умолчанию).
- **Сообщать об отключённых устройствах** — Произносить сопряжённые, но не подключённые устройства.
- **Сообщать об устройствах с неизвестным состоянием** — Произносить устройства с неопределимым состоянием подключения. Bluetooth LE обычно имеют это состояние.

### Что произносить для каждого устройства

- **Показывать тип подключения (Classic / LE)** — Добавить метку Bluetooth Classic или Bluetooth Low Energy.
- **Показывать длительность подключения** — Произносить, как долго устройство подключено.
- **Произносить общее время подключения с последней зарядки** — Выбрать произносимое время и включить измерение (по умолчанию включено).
  - Установлено: общее время подключения с последней зарядки; сохраняется при отключениях и перезапусках NVDA, работает с Classic и LE.
  - Снято: только текущий сеанс по данным Windows. Windows предоставляет его лишь для Classic, поэтому у LE в этом режиме времени нет.
- **Показывать оценку зарядного футляра в отчёте** — Добавить оценку оставшегося числа зарядок футляра к строке наушников (по умолчанию выключено, см. «Зарядный футляр»).

### Статистика

- **Просмотреть статистику батарей...** — Открыть окно статистики (ниже).
- **Максимум завершённых циклов на устройство** — От 5 до 5000, по умолчанию 500. При превышении удаляются самые старые.
- **Удалять завершённые циклы старше указанного числа дней** — 0 сохраняет все (по умолчанию).

### Оповещения

- **Включить оповещение о низком заряде (по умолчанию для всех устройств)** — Оповещать, когда заряд подключённого устройства ниже его порога. Устройства следуют этой настройке, если не заданы отдельные параметры (см. «Оповещения»). Диалог низкого заряда показывается всегда.
- **Порог низкого заряда по умолчанию** — Процент для устройств без собственного порога (5–50%, по умолчанию 20%).
- **Способы оповещения (для всех оповещений)** — Совмещаемые флажки:
  - **Произносить оповещение** (по умолчанию установлен)
  - **Воспроизводить двойной сигнал**
  - **Воспроизводить звук оповещения** (см. «Звуки оповещений»)
- **Открыть папку звуков...** — Открыть папку файлов для их замены.
- **Оповещение о снижении заряда: оповещать при каждом снижении на указанное число процентных пунктов** — От 1 до 50, по умолчанию 10.
- **Проверять изменения подключения устройств каждые указанное число секунд** — От 5 до 300, по умолчанию 15. Используется, только пока у устройства включено оповещение о подключении или отключении.

## Учёт времени подключения

Дополнение записывает время подключения между двумя зарядками, показывая реальное время работы от одного заряда. Работает в фоне и управляется параметром **Произносить общее время подключения с последней зарядки**.

- Учёт начинается при первом обнаружении устройства с любым зарядом. Поэтому первый цикл может быть короче полного, если батарея тогда была не полной.
- Считается только время, когда устройство считается подключённым. Отключения не учитываются, но накопленное время сохраняется.
- Зарядка определяется, когда уровень минимум на 15 процентных пунктов выше минимального уровня текущего цикла. Работает и для устройств, не достигающих 100%. Завершённый цикл сохраняется, счёт начинается с нуля. Рост заряда (зарядка) не учитывается.
- Если Windows сообщает для Classic большее время подключения, используется оно. У LE такого значения нет: учитывается только время наблюдения дополнением.
- Промежутки между наблюдениями дольше 15 минут (например сон компьютера) не учитываются.
- Циклы короче 30 минут не сохраняются как завершённые.
- Устройства определяются по адресу Bluetooth, не по имени. Два одинаковых имени имеют отдельные записи; переименование в Windows сохраняет данные.
- Измерение можно остановить (см. «Статистика батарей»). Данные сохраняются; время подключения затем берётся из Windows, если доступно.

### Устройства, подключённые не постоянно

Некоторые устройства включены, но редко подключаются к компьютеру. Например, трёхрежимная клавиатура используется через приёмник 2,4 ГГц, а Bluetooth подключается лишь для проверки батареи. Время подключения очень мало, и циклы с подключением меньше 30 минут не сохраняются, поэтому полезных записей нет. Выберите **Учитывать прошедшее время** в меню «Измерение» устройства окна статистики. По умолчанию выключено, задаётся отдельно.

При включении:

- Цикл идёт от зарядки до последнего наблюдаемого снижения уровня. Он не продолжается до следующей проверки: уровень известен только при чтении, а Windows может показывать старое значение для отключённого устройства.
- Зарядка обнаруживается при первом чтении после неё. Её момент ставится посередине между последним чтением до зарядки и этим чтением.
- Оценки (полный заряд, расход, остаток, тенденция) и «Интервал зарядки» используют это время; от двух дней оно показывается в днях. Первый цикл начинается с первого обнаружения при любом уровне.
- Строка отчёта показывает время с последней зарядки вместо времени подключения.
- Цикл запоминает способ учёта. Статистика использует лишь циклы с текущим способом устройства. Остальные остаются в списке со способом в столбце «Способ учёта времени».
- Изменение способа начинает текущий цикл заново.

Периодически читайте батарею такого устройства: подключите Bluetooth и нажмите сочетание. Чем реже чтение, тем ниже точность; две зарядки между чтениями будут считаться одним циклом.

### Устройства, не разряжающиеся до 0%

Некоторые сообщают неравномерное снижение заряда. Например, клавиатура долго остаётся на 100%, затем быстро разряжается и прекращает работать при 55% или 60%. Вы привыкаете заряжать её раньше, например при 70%. Оценки «Полный заряд» и «Осталось сейчас» предполагают равномерное снижение до 0%, поэтому сильно завышены: фактическое время между вашими зарядками гораздо короче.

Выберите **Обычный уровень подзарядки...** в меню «Измерение» и введите уровень, например 70. По умолчанию выключено (0), задаётся отдельно.

При включении:

- «Полный заряд (оценка)» становится временем от полной батареи до вашего уровня — временем между вашими зарядками.
- «Осталось сейчас (оценка)» становится временем до вашего уровня; равно нулю, если заряд уже на нём или ниже.
- Расход, длительность циклов и обнаружение зарядок не меняются.
- «Измерение» в сводке показывает уровень, например «включено, зарядка при 70%».

Для равномерно разряжающихся устройств оставьте выключенным. Оценки остаются приблизительными из-за неравномерности; надёжнее реальные интервалы: «Среднее», «Самый короткий», «Самый долгий», «Интервал зарядки».

## Статистика батарей

**Просмотреть статистику батарей...** в настройках открывает окно с двумя списками. Команда «Открыть статистику батарей Bluetooth» в «Жестах ввода» открывает его напрямую. Записи видны и при выключенном измерении.

Порядок как в голосовом отчёте: подключённые, неизвестные, отключённые, затем по имени. Отсутствовавшие при последнем сканировании идут в конце.

### Сводка по устройствам

Одна строка на устройство:

- **Состояние** — Подключение при последнем сканировании.
- **Измерение** — Выключено, включено или включено с прошедшим временем. При заданном уровне подзарядки он добавляется, например «зарядка при 70%».
- **Оповещения** — Включённые оповещения, например «низкий заряд 20%, снижение заряда» или «нет».
- **Циклы** — Число завершённых циклов.
- **Среднее**, **Самый короткий**, **Самый долгий** — Время подключения завершённых циклов.
- **Полный заряд (оценка)** — Оценка времени работы от полного заряда по расходу в каждом цикле. Позволяет сравнивать циклы, начавшиеся не со 100%.
- **Расход заряда** — Процентные пункты за час подключения, либо за день при медленном расходе.
- **Интервал зарядки** — Среднее время между двумя зарядками.
- **Последняя зарядка** — Время последнего обнаружения зарядки.
- **Тенденция** — Последние 3 цикла относительно предыдущих: например «на 12% короче» или «стабильно» (разница менее 5%). Нужно минимум 4 цикла.
- **Осталось сейчас (оценка)** — Оставшееся время подключения при обычном расходе по последнему уровню.
- **Футляр: использовано (зарядок, оценка)** и **Футляр: осталось (зарядок, оценка)** — Использованные и оставшиеся зарядки, только для устройств с футляром (см. «Зарядный футляр»). Столбцы добавляются при первом включении футляра; их можно скрыть.

### Циклы

Сначала виден только незавершённый («текущий») цикл каждого устройства. Завершённые свёрнуты, новые идут первыми. Space на любой строке устройства, двойной щелчок или контекстное меню (Applications) разворачивают их; повторное действие сворачивает. NVDA говорит «Развёрнуто» или «Свёрнуто». Столбцы:

- **Цикл** — Номер.
- **Состояние раскрытия** — «свёрнуто» или «развёрнуто» на текущем цикле; пусто, если завершённых нет.
- **Длительность** — Время подключения цикла.
- **Батарея** — Начальный и минимальный заряд, например «от 100% до 23%».
- **Расход заряда** — Пункты за час этого цикла.
- **Полный заряд (оценка)** — Оценка работы от полного заряда для цикла.
- **Завершён** — Когда обнаружена зарядка, завершившая цикл.
- **Способ учёта времени** — Время подключения или прошедшее время (см. «Устройства, подключённые не постоянно»). Добавляется при первом учёте прошедшего времени; можно скрыть.

Оценки игнорируют циклы с расходом меньше 10 пунктов: Bluetooth часто сообщает заряд крупными шагами. Пустая ячейка означает недостаток данных. Чем больше циклов, тем надёжнее оценка.

## Команды окна статистики

Списки используют общие команды. Большинство имеют клавиши; все есть в контекстном меню (Applications). Открывающие подменю или диалог идут первыми, имеющие клавишу — последними.

### Измерение

Подменю с двумя переключаемыми пунктами:

- **Измерять это устройство** — Остановить или возобновить измерение, сохраняя данные.
- **Учитывать прошедшее время (для устройств, подключённых не постоянно)** — Считать время с последней зарядки вместо подключения. См. соответствующий раздел.
- **Обычный уровень подзарядки...** — Уровень обычной зарядки устройства с неравномерными показаниями. См. «Устройства, не разряжающиеся до 0%».

### Оповещения

Оповещения устройства. См. ниже.

### Выбор

Переключить выбор текущей строки (**Control+Space**), выбрать всё (**Control+A**), снять весь выбор, обратить выбор, выбрать строки этого устройства. Поддерживается множественный выбор; NVDA говорит «выбрано» для выбранных строк. Стрелки без модификатора выбирают только текущую строку. Чтобы набрать выбор, перемещайтесь Control+стрелками и нажимайте Control+Space на каждой строке.

### Сортировка

Без клавиши. Выберите порядок устройств (отчёт, имя, число циклов, среднее время, оценка полного заряда, последняя зарядка, время текущего цикла, расход или вручную) и завершённых циклов каждого устройства (новые, старые, долгие, короткие первыми или вручную). Отмеченный вариант используется, выбор запоминается. **Вручную** позволяет задать порядок (см. «Перемещение устройства или цикла»).

### Перемещение устройства или цикла

**Control+Shift+стрелка вверх** и **Control+Shift+стрелка вниз**. Нужна ручная сортировка: выберите «Вручную» в «Сортировка» → «Устройства по» для устройств, «Циклы по» для циклов. При первом выборе для устройств текущий порядок становится вашим.

- В сводке и на текущем цикле перемещается устройство со всеми строками.
- На завершённом цикле развёрнутого устройства перемещается этот цикл среди его завершённых циклов.

NVDA произносит новую позицию, например «2 из 5»; сигнал означает границу списка. Порядок запоминается. Впервые обнаруженное устройство и только что завершённый цикл помещаются первыми.

### Перемещение списков

**Control+Shift+стрелка влево** и **Control+Shift+стрелка вправо** ставят список с фокусом до или после другого. Окно открывается на первом списке, позволяя поставить часто используемый первым. Порядок запоминается.

### Выбрать столбцы

Без клавиши. Открывает флажки для необязательных столбцов обоих списков. «Устройство» и «Цикл» видны всегда. Control+Shift+стрелка вверх или вниз перемещает столбец; порядок используется при показе, копировании и экспорте. Выбор запоминается.

### Развернуть и свернуть

**Space** в списке циклов показывает или скрывает завершённые циклы устройства.

### Переименовать устройство

**F2** задаёт собственное имя устройству текущей строки. Пустое или исходное имя возвращает имя Windows. Используется в статистике, голосовом отчёте и оповещениях.

### Копирование

- **Control+C** копирует текущую строку.
- **Control+Shift+C** копирует всё о текущем устройстве (сводку и все циклы, включая свёрнутые).

Копируются только видимые столбцы в парах «Заголовок: значение».

### Отметить футляр как заряженный

**Control+Shift+R**, только для устройства с футляром. Сообщает, что вы зарядили футляр, чтобы считать использованные зарядки с нуля. См. «Зарядный футляр».

### Экспорт

**Control+E** открывает меню:

- **Что экспортировать** — Выбранные строки, текущее устройство или все строки списка. Отмеченный вариант используется.
- **Включать подробные значения** — По умолчанию включено, выбор запоминается. Добавляет идентификацию (адрес и оба имени) и точные значения: секунды, проценты, израсходованные пункты, даты ISO 8601. Иначе экспортируются видимые столбцы.
- **Копировать в буфер обмена как** и **Сохранить в файл как** — Обычный текст, таблица Markdown, CSV, значения с табуляцией (для вставки в электронную таблицу), JSON (числа остаются числами) или таблица HTML. CSV сохраняется с меткой порядка байтов, чтобы Excel верно показывал символы.
- **Открыть HTML-отчёт в браузере** — Создаёт страницу с заголовком и таблицей, открывает в браузере.

Экспорт можно сразу передать человеку или инструменту ИИ.

### Обновление

**F5** повторяет сканирование и обновляет окно; иначе оно отражает только момент открытия.

### Удаление

- **Control+Delete** удаляет текущую строку или все выбранные строки.
- **Control+Shift+Delete** удаляет устройство текущей строки со всеми данными.

Всегда запрашивается подтверждение («Да» или «Нет»). На незавершённом цикле удаление начинает текущий цикл с нуля. В сводке удаление строки удаляет устройство. Если измерение включено, удалённое устройство начнёт с нуля при следующей проверке.

## Оповещения

Для каждого устройства выбираются следующие оповещения в окне статистики (контекстное меню **Оповещения**; одноимённый столбец сводки показывает активные). Все используют выбранные в настройках способы.

### Низкий заряд

Оповещает один раз при низком заряде подключённого устройства, до восстановления заряда. Также показывает предупреждение. **Порог низкого заряда...** в меню даёт три варианта:

- **Использовать настройку по умолчанию** — Следовать **Включить оповещение о низком заряде** и общему порогу. Если выключено в настройках, устройство не оповещает.
- **Использовать собственный порог** — От 5 до 50%. Оповещает даже при выключенном общем оповещении.
- **Никогда не оповещать для этого устройства** — Без оповещения о низком заряде независимо от настроек.

### Снижение заряда

По умолчанию выключено. Оповещает при снижении на заданное число пунктов с прошлого оповещения, начиная с первого обнаруженного уровня и заново при росте (зарядке). Шаг зависит от устройства: 1%, 10% или больше. При стандартных 10 пунктах устройство с шагом 10% оповещает на каждом шаге. Если при той же проверке возникает низкий заряд этого устройства, сообщается только он.

### Подключение и отключение устройства

По умолчанию выключено. Оповещает при смене подключённого и отключённого состояний. Как при учёте времени, устройство считается подключённым, пока не известно обратное. Поэтому LE с неизвестным состоянием оповещает об отключении лишь при соответствующих данных Windows. Первая проверка после запуска NVDA только запоминает состояние. Затем проверки идут каждые несколько секунд (см. настройки).

### Зарядный футляр

Для полностью беспроводных наушников с футляром. По умолчанию выключено для каждого устройства. Windows сообщает заряд наушников, не футляра, поэтому дополнение оценивает число зарядок от него. **Зарядный футляр...** в меню оповещений открывает поля:

- **Оповещать о зарядном футляре** — Включить оценку и оповещение.
- **Время работы наушников от одной зарядки (часы)** и **Общее время работы с футляром (часы)** — Например 10 и 52 часа. Тогда футляр заряжает примерно 4,2 раза: 52 разделить на 10, минус исходный заряд самих наушников.
- **Использовать статистику** — Заполнить время от зарядки оценкой полного заряда, округлённой до получаса.
- **Оповещать, когда осталось меньше зарядок, чем** — По умолчанию 1.

При каждой обнаруженной зарядке наушников полученные пункты добавляются к использованным зарядкам (100 пунктов — одна зарядка). Оповещение выдаётся, когда наушники достигают своего или общего низкого порога, а оценка оставшихся зарядок футляра ниже указанного поля. Пора зарядить оба. Оповещает один раз до восстановления заряда наушников и показывает диалог, как при низком заряде.

После оповещения при следующей обнаруженной зарядке наушников (вы достали их и подключили) дополнение спрашивает о зарядке футляра. **Да** считает использованные зарядки с нуля. **Нет**, ответ по умолчанию, продолжает счёт.

В любой момент **Отметить футляр как заряженный** (Control+Shift+R в статистике) начинает счёт заново. Каждый раз запоминается число зарядок футляра в этом раунде. С третьего завершённого раунда используется типичное значение последних пяти вместо указанных вами времён работы.

Ограничения:

- Хорошо работает лишь при использовании наушников преимущественно с этим компьютером. Зарядки при работе с телефоном или другим устройством не учитываются: футляр кажется полнее, чем есть.
- О каждой зарядке футляра нужно сообщать ответом или отметкой: дополнение не может узнать само.
- Должно быть включено измерение времени подключения, как для статистики.
- Это оценка, а не измерение.

### Звуки оповещений

Речь сообщает, например, «имя устройства подключено» или «имя устройства, заряд 80%»; двойной сигнал одинаков для всех оповещений; отдельный звук — файл .wav в папке `sounds` дополнения рядом с `globalPlugins`. Откройте **Открыть папку звуков...** и замените файл. При отсутствии файла звучит сигнал. Несколько звуков воспроизводятся последовательно. Файлы:

- `lowBattery.wav`
- `levelDrop.wav`
- `deviceConnected.wav`
- `deviceDisconnected.wav`
- `chargingCase.wav`

## Фоновое наблюдение

При включённом низком заряде, учёте времени или любом оповещении устройства батареи проверяются в фоне каждые 5 минут. Пока есть оповещение о подключении или отключении, подключения проверяются чаще (каждые несколько секунд, см. настройки); остальное по-прежнему каждые 5 минут.

## Данные и настройки

Записи хранятся в `btBatterytics_usage.json` в папке пользовательской конфигурации NVDA. Скопируйте файл для резервной копии. Удалите при закрытой NVDA, чтобы начать заново.

При первом запуске BT-Batterytics переносит прежние данные: копирует записи из `blueToothBatteryReport_usage.json` (старый файл не меняется) и берёт настройки из прежнего раздела. Записи до идентификации по адресу переходят на адрес одноимённого устройства при первом обнаружении.
