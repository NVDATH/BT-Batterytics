# BT-Batterytics

BT-Batterytics 报告蓝牙设备的电量，记录各设备在两次充电之间的连接时间，并显示相关统计。

它是 haitun001 和 cary-rowen 开发的 [BlueToothBatteryReport](https://github.com/haitun001/BlueToothBatteryReport) 的修改版（参见下文“致谢与许可证”）。

本插件支持多设备电量报告，依次播报所有能够检测到电量的蓝牙设备。播报顺序为：已连接、状态未知、未连接。

## 快捷键

- 在没有电池的电脑（台式机）上使用 `NVDA+Shift+B`，在有电池的电脑（笔记本或平板）上使用 `NVDA+Alt+B` — 按一次朗读电量状态，按两次将报告复制到剪贴板，按三次打开设置面板。

NVDA+Shift+B 是 NVDA 自身的电池状态命令。台式机没有电池，因此插件在此类电脑上使用该手势。有电池的电脑改用 NVDA+Alt+B，以保留 NVDA 原有命令。插件在 NVDA 启动时根据 Windows 提供的信息作出选择；若 Windows 无法确定，则按有电池处理。可在 NVDA → 选项 → 按键与手势的 BT-Batterytics 类别中更改手势。此类别还包含“打开蓝牙电池统计”命令，默认未分配手势。

## 语音格式

有电量信息时，每台设备按以下格式播报：

- `设备名称 电量 xx%`

还可选择显示连接类型和连接时间：

- `设备名称（Classic）电量 xx%`
- `设备名称（LE）电量 xx%`
- `设备名称 电量 xx%（已连接 2 小时 5 分钟）`

如果您为设备设置了别名（参见“电池统计”），将播报该名称，而非 Windows 提供的名称。

## 设置

专用设置页面位于 NVDA → 选项 → 设置 → BT-Batterytics。

### 报告哪些设备

- **报告已连接的设备** — 播报当前已连接的设备（默认开启）。
- **报告未连接的设备** — 播报已配对但未连接的设备。
- **报告状态未知的设备** — 播报无法确定连接状态的设备。Bluetooth LE 设备通常被报告为此状态。

### 每台设备播报哪些信息

- **显示连接类型（Classic / LE）** — 添加标签，标明设备使用 Bluetooth Classic 还是 Bluetooth Low Energy。
- **显示连接时长** — 播报设备已连接多久。
- **朗读自上次充电以来的总连接时间** — 选择播报哪种时间，并开启计时（默认开启）。
  - 选中：自设备上次充电以来累计的连接时间。断开连接或重启 NVDA 后仍会保留，适用于 Classic 和 LE 设备。
  - 未选中：仅使用 Windows 报告的当前连接会话时长。Windows 仅为 Classic 设备提供此值，因此 LE 设备在此模式下没有连接时间。
- **在报告中显示充电盒估算值** — 在耳机的报告行中加入充电盒剩余可充电次数的估算值（默认关闭，参见“充电盒”）。

### 统计

- **查看电池统计...** — 打开电池统计窗口（见下文）。
- **每台设备最多保留的已完成周期数** — 范围为 5 至 5000，默认 500。超过此数量时删除最早的周期。
- **删除早于此天数的已完成周期** — 0 表示全部保留（默认值）。

### 提醒

- **启用低电量提醒（所有设备的默认设置）** — 当已连接设备的电量低于其提醒阈值时提醒。除非您单独为设备选择其他设置，否则各设备均遵循此选项（参见“提醒”）。低电量提醒始终会显示对话框。
- **默认低电量提醒阈值** — 未设置独立阈值的设备在此电量触发低电量提醒（5–50%，默认 20%）。
- **提醒方式（适用于所有提醒）** — 可组合使用的复选框列表：
  - **语音朗读提醒**（默认选中）
  - **播放两声蜂鸣**
  - **播放提醒音效**（参见“提醒音效”）
- **浏览声音文件夹...** — 打开提醒音效文件夹，以便替换文件。
- **电量下降提醒：电量每下降以下百分点数时提醒** — 范围为 1 至 50，默认 10。
- **设备连接状态检查间隔（秒）** — 范围为 5 至 300，默认 15。仅在有设备启用连接或断开连接提醒时使用。

## 连接时间跟踪

插件记录每台设备在两次充电之间的连接时间，让您了解单次充电的实际续航。此功能在后台运行，由 **朗读自上次充电以来的总连接时间** 控制。

- 插件首次发现设备时即开始跟踪，不论当时电量多少。因此，若设备当时未满电，首个周期可能短于实际的完整周期。
- 仅统计设备被视为已连接时的时间。未连接时不计时，但保留此前累计的总时间。
- 当电量比当前周期内观察到的最低电量高出至少 15 个百分点时，判定为已充电。因此，电量从不达到 100% 的设备也可使用。已完成周期会被保存，计时从零重新开始。电量上升（充电）期间不计时。
- 如果 Windows 报告某台 Classic 设备的连接时间长于插件累计的时间，则采用较长的值。LE 设备没有此值，因此其总时间仅覆盖插件实际观察到的连接时间。
- 两次观测之间超过 15 分钟的间隔（例如电脑睡眠期间）不计入。
- 短于 30 分钟的周期不保存为已完成周期。
- 通过蓝牙地址而非名称识别设备。同名的两台设备分别记录，在 Windows 中重命名设备后仍保留其数据。
- 可停止某台设备的计时（参见“电池统计”）。数据会保留，之后使用 Windows 报告的连接时间（若有）。

### 并非始终连接的设备

有些设备保持开机，却很少连接到电脑。例如，您通过 2.4 GHz 接收器使用三模键盘，仅偶尔通过蓝牙连接以检查电量。此类设备的连接时间很短，而连接时间不足 30 分钟的周期不会保存，因此无法形成有用记录。对于这些设备，请在统计窗口中设备的“计时”菜单内选择 **按经过时间计时**。此选项默认关闭，按设备单独设置。

开启后：

- 周期从充电时刻计时，到最后一次观察到电量下降的时刻为止。不会一直计到您下次检查时，因为只有读取时才能知道电量，且 Windows 可能为未连接设备显示旧读数。
- 充电后的首次电量读取会检测出充电。充电时刻取充电前最后一次读数与此次读数之间的中点。
- 估算值（满电续航、耗电速率、剩余时间、趋势）及“充电间隔”列采用这些时间，两天及以上以天为单位显示。首个周期从插件首次发现设备时开始，不论当时电量多少。
- 设备报告行显示自上次充电以来的时间，而非连接时间。
- 每个周期会记住其计时方式。设备统计仅采用与当前计时方式相同的周期。其他周期仍保留在周期列表中，其方式显示在“计时方式”列。
- 更改计时方式会重新开始当前周期。

请不时读取此类设备的电量：通过蓝牙连接后按快捷键。读取越不频繁，估算越不准确；若两次读数之间充电两次，这两个周期将被当作一个周期。

### 电量不会降至 0% 的设备

某些设备报告的电量下降并不均匀。例如，某键盘的电量长时间保持在 100%，随后快速下降，并在 55% 或 60% 时停止工作。您会逐渐习惯提前充电，例如在 70% 时充电以确保可用。统计中的估算值（满电续航、当前剩余时间）假定电量均匀下降至 0%，因此对这类设备会严重高估：您两次充电之间的实际续航远短于估算值。

对于此类设备，请在设备的“计时”菜单中选择 **通常充电电量阈值...**，输入您通常为其充电时的电量，例如 70。默认关闭（0），按设备单独设置。

开启后：

- “满电续航（估算）”变为设备从满电降至您设置的电量所能持续的时间，也就是两次充电之间的时间。
- “当前剩余时间（估算）”变为电量降至您设置的阈值前的剩余时间。如果已达到或低于该阈值，则为零。
- 耗电速率、周期时长及充电检测方式不变。
- 汇总列表中的“计时”列会显示该阈值，例如“开启，电量为 70% 时充电”。

对于电量均匀下降的设备，请保持关闭。由于这类设备的电量下降不均匀，估算仍然只是粗略值；最可靠的数字是两次充电之间的实际时间：“平均”“最短”“最长”和“充电间隔”。

## 电池统计

设置面板中的 **查看电池统计...** 会打开一个包含两个列表的窗口。“按键与手势”对话框中的“打开蓝牙电池统计”命令可直接打开此窗口。即使计时已关闭，窗口仍会显示保存的记录。

设备的排列顺序与语音报告一致：已连接、未知、未连接，然后按名称排列。未出现在最近一次扫描中的设备排在最后。

### 各设备汇总

每台设备占一行：

- **状态** — 最近一次扫描中的连接状态。
- **计时** — 是否对设备计时：关闭、开启，或按经过时间计时。设置通常充电电量阈值后，会追加显示，例如“电量为 70% 时充电”。
- **提醒** — 此设备已开启的提醒，例如“低电量 20%，电量下降”，或“无”。
- **周期** — 已完成周期数。
- **平均**、**最短**、**最长** — 已完成周期的连接时间。
- **满电续航（估算）** — 根据各周期消耗的电量估算满电续航，使并非从 100% 开始的周期也能进行比较。
- **耗电速率** — 通常为每连接一小时消耗的电量百分点数；耗电较慢的设备则以每天计。
- **充电间隔** — 两次充电之间的平均时间。
- **上次充电** — 最近一次检测到充电的时间。
- **趋势** — 最近 3 个周期与更早周期的比较，例如“缩短 12%”或“稳定”（差异小于 5%）。至少需要 4 个周期。
- **当前剩余时间（估算）** — 根据最近观察到的电量及设备通常的耗电速率估算剩余连接时间。
- **充电盒已用（估算充电次数）** 和 **充电盒剩余（估算充电次数）** — 充电盒已提供及剩余可提供的充电次数，仅用于具有充电盒的设备（参见“充电盒”）。首次启用充电盒时添加这两列，也可隐藏。

### 周期

最初，每台设备仅显示正在进行的周期（“当前”）。已完成周期处于折叠状态，展开后最新的排在前面。在设备任一行上按 Space、双击，或使用上下文菜单（Applications 键）可展开，再执行同样操作可折叠。NVDA 会朗读“已展开”或“已折叠”。列如下：

- **周期** — 周期编号。
- **展开状态** — 当前周期所在行显示“已折叠”或“已展开”；没有已完成周期的设备留空。
- **时长** — 此周期的连接时间。
- **电量** — 周期开始时的电量与达到的最低电量，例如“100% 至 23%”。
- **耗电速率** — 此周期每小时消耗的电量百分点数。
- **满电续航（估算）** — 此周期估算出的满电续航。
- **结束时间** — 检测到导致此周期结束的充电的时间。
- **计时方式** — 此周期使用连接时间还是经过时间（参见“并非始终连接的设备”）。首次按经过时间计时时添加此列，也可隐藏。

估算会忽略耗电不足 10 个百分点的周期，因为蓝牙电量通常以较大的步长报告。空白单元格表示数据尚不足。记录的周期越多，估算越可靠。

## 统计窗口命令

两个列表共用相同命令。大多数命令有快捷键，所有命令也都在上下文菜单（Applications 键）中。菜单中，打开子菜单或对话框的命令排在前面，有快捷键的命令排在后面。

### 计时

设备的子菜单，包含两个可勾选项目：

- **对此设备计时** — 停止或重新开启此设备的计时，保留数据。
- **按经过时间计时（适用于并非始终连接的设备）** — 统计自上次充电以来的时间，而非连接时间。参见“并非始终连接的设备”。
- **通常充电电量阈值...** — 对于报告电量不均匀的设备，设置您通常为其充电时的电量。参见“电量不会降至 0% 的设备”。

### 提醒

设备的提醒。参见下文“提醒”。

### 选择

切换当前行的选择状态（**Control+Space**）、全选（**Control+A**）、全不选、反选、选择此设备的所有行。与普通列表一样，这些列表支持多选，因此 NVDA 会对选中的行朗读“已选择”。仅使用方向键移动时，只选择当前行。若要逐步多选，请使用 Control+方向键移动，再对各行按 Control+Space。

### 排序

无快捷键。可选择设备顺序（报告顺序、名称、周期数、平均时间、满电续航估算、上次充电、当前周期时长、耗电速率或手动），以及各设备已完成周期的顺序（最新、最早、最长、最短优先，或手动）。勾选项即当前使用的顺序，且会记住您的选择。选择 **手动** 后，可自行决定顺序（参见“移动设备或周期”）。

### 移动设备或周期

**Control+Shift+上箭头** 和 **Control+Shift+下箭头**。需要使用手动排序：在“排序”菜单中，要移动设备，请在“设备排序依据”下选择“手动”；要移动周期，请在“周期排序依据”下选择“手动”。首次为设备选择“手动”时，当前顺序将成为您的自定义顺序。

- 在汇总列表中，或周期列表的当前周期行上，按键将移动设备及其全部行。
- 在已展开设备的已完成周期上，按键将在该设备的已完成周期之间移动该周期。

NVDA 会朗读新位置，例如“第 2 项，共 5 项”；蜂鸣表示该行已到达边界。顺序会被记住。插件首次发现的设备及刚完成的周期会放在最前面。

### 移动列表

**Control+Shift+左箭头** 和 **Control+Shift+右箭头** 将当前聚焦的列表移到另一个列表之前或之后。窗口打开时聚焦第一个列表，因此您可以将最常查看的列表放在前面。顺序会被记住。

### 选择列

无快捷键。打开复选框列表，每个列表的每个可选列各对应一项。“设备”和“周期”列始终显示。在列上按 Control+Shift+上箭头或 Control+Shift+下箭头可移动该列，此顺序用于显示、复制和导出。您的选择会被记住。

### 展开与折叠

在周期列表上按 **Space**，显示或隐藏设备的已完成周期。

### 重命名设备

**F2** 为当前行所属的设备设置别名。留空或输入原名称可恢复 Windows 提供的名称。此名称用于统计、语音报告和提醒。

### 复制

- **Control+C** 复制当前行。
- **Control+Shift+C** 复制当前设备的全部内容（汇总及所有周期，包括折叠的周期）。

仅复制当前显示的列，格式为“列标题：值”。

### 标记充电盒已充电

**Control+Shift+R**，仅适用于有充电盒的设备。告知插件您已给充电盒充电，以便将其已用充电次数从零重新计算。参见“充电盒”。

### 导出

**Control+E** 打开“导出”菜单，包含以下部分：

- **导出内容** — 所选行、当前设备或列表中的全部行。勾选项即当前使用的选项。
- **包含详细数值** — 默认选中并记住选择。除列表列外，还加入设备身份信息（地址及两个名称）和精确值：秒数、电量百分比、已用电量百分点、ISO 8601 日期。不选中时，仅导出列表中显示的列。
- **复制到剪贴板的格式** 和 **保存到文件的格式** — 纯文本、Markdown 表格、CSV、制表符分隔值（用于粘贴到电子表格）、JSON（数值保持为数值类型），或 HTML 表格。CSV 文件使用字节顺序标记保存，以便 Excel 正确显示所有字符。
- **在浏览器中打开 HTML 报告** — 创建包含标题和表格的页面，并在您的浏览器中打开。

导出内容可直接交给他人或 AI 工具使用。

### 刷新

**F5** 重新扫描设备并更新窗口。否则，窗口仅反映打开时的状态。

### 删除

- **Control+Delete** 删除当前行。如果选中了多行，则删除所有选中行。
- **Control+Shift+Delete** 删除当前行所属设备及其全部数据。

始终先询问确认（是或否）。对于正在进行的周期，“删除”会将当前周期从零重新开始。在汇总列表中，删除行即删除设备。若已开启计时，删除的设备会在下次检查时从零重新开始。

## 提醒

每台设备均可设置以下提醒。在统计窗口中按设备选择（上下文菜单中的 **提醒**；汇总列表的“提醒”列显示已启用的项目）。所有提醒均使用设置中勾选的提醒方式。

### 低电量

已连接设备电量低时提醒一次，在电量回升前不会再次提醒，同时显示警告对话框。在“提醒”菜单中，**低电量阈值...** 打开包含三种选项的对话框：

- **使用默认设置** — 设备遵循设置中的 **启用低电量提醒** 及默认阈值。若设置中关闭低电量提醒，此设备不提醒。
- **使用自定义阈值** — 阈值范围为 5 至 50%。即使设置中关闭了低电量提醒，此设备仍在此阈值提醒。
- **此设备永不提醒** — 无论设置如何，均不进行低电量提醒。

### 电量下降

默认关闭。自上次提醒起，电量每下降设置中指定的百分点数时提醒；从首次发现设备时的电量开始计算，并在电量上升（充电）时重新开始。蓝牙设备报告电量的步长取决于设备：有些每 1% 报告一次，有些每 10% 或更多才报告。默认设为 10 个百分点时，以 10% 为步长报告的设备每下降一步便提醒。如果同一设备在同一次检查中触发低电量提醒，则只发出低电量提醒。

### 设备连接与设备断开连接

默认关闭。在设备于已连接和未连接之间切换时提醒。与连接时间计时相同，只要未明确知道设备已断开，就视为已连接。因此，Bluetooth LE 设备（状态未知）仅在 Windows 报告为未连接时才发出断开连接提醒。NVDA 启动后的第一次检查仅记录状态。此后每隔数秒重新检查设备（参见设置）。

### 充电盒

适用于附带充电盒的真无线耳机。默认关闭，按设备单独设置。Windows 报告的是耳机电量，而非充电盒电量，因此插件估算充电盒已为耳机充电的次数。在设备的“提醒”菜单中，**充电盒...** 打开包含以下字段的对话框：

- **充电盒提醒** — 开启此设备的估算及提醒。
- **耳机单次充电续航（小时）** 和 **含充电盒的总续航（小时）** — 耳机的续航，例如 10 小时和 52 小时。则充电盒约可给耳机充电 4.2 次：52 除以 10，再减去耳机自身原有的第一次满电。
- **使用统计数据** — 使用统计中的满电续航估算值填写单次充电续航，并按半小时取整。
- **剩余充电次数少于此值时提醒** — 默认 1。

每次插件观察到耳机已充电，便将增加的电量百分点累计到已用充电次数中（100 个百分点计为一次充电）。当耳机电量达到设备的低电量阈值或默认阈值，且估计充电盒剩余次数少于上述字段设定值时，会发出提醒。此时应将充电盒与耳机一起充电。提醒只发出一次，直到耳机电量回升，并像低电量提醒一样显示警告对话框。

插件也会询问您。提醒后，下一次观察到耳机已充电（您将其从充电盒取出并连接）时，会询问您是否也给充电盒充电。选择 **是** 会将充电盒的已用充电次数从零重新计算。默认答案 **否** 则继续累计。

您可随时使用 **标记充电盒已充电**（统计窗口中的 Control+Shift+R）从零重新计算。每次标记时，插件都会记住充电盒在这一轮提供的充电次数。从第三轮完成后，改用最近五轮的典型值，而非您填写的续航时间。

估算有以下限制：

- 仅当耳机主要用于这台电脑时效果较好。用于其他设备（例如手机）期间发生的充电不会计入，因此看起来充电盒的剩余电量会比实际更多。
- 每次给充电盒充电后，都必须通过回答问题或手动标记告知插件，因为插件无法自行得知。
- 与统计一样，必须开启设备的连接时间计时。
- 这是估算值，并非实际测量值。

### 提醒音效

提醒方式中，语音会朗读例如“设备名称 已连接”或“设备名称 电量 80%”；所有提醒使用相同的两声蜂鸣；各类提醒音效则是插件 `sounds` 文件夹中的 .wav 文件（与 `globalPlugins` 文件夹相邻）。使用设置中的 **浏览声音文件夹...** 打开文件夹，替换文件即可更改音效。若文件缺失，则改用蜂鸣。多个提醒同时出现时，音效会依次播放。文件如下：

- `lowBattery.wav`
- `levelDrop.wav`
- `deviceConnected.wav`
- `deviceDisconnected.wav`
- `chargingCase.wav`

## 后台监测

启用低电量提醒、连接时间跟踪或某台设备的任一提醒时，插件每 5 分钟在后台检查电量。有设备启用连接或断开连接提醒时，会更频繁地检查连接状态（每隔数秒，参见设置），其余工作仍每 5 分钟执行一次。

## 数据与设置

记录保存在 NVDA 用户配置文件夹中的 `btBatterytics_usage.json` 内。复制此文件即可备份。若要重新开始，请在 NVDA 未运行时删除此文件。

BT-Batterytics 首次运行时，会接管旧名称下保存的内容：从 `blueToothBatteryReport_usage.json` 复制记录（旧文件保持不变），并从旧设置节中读取设置。在改用地址识别设备之前保存的记录，会在首次发现同名设备时迁移到该设备的地址下。
